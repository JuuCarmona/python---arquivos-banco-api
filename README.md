# Alura – Persistência de dados com Python

Exercícios do curso **Persistência de dados com Python: banco de dados, arquivos e APIs REST**, da Alura.

## O que estou praticando

- Leitura e escrita de arquivos com `open()` e `with`
- Banco de dados com Python
- Consumo e criação de APIs REST

## Estrutura

| Pasta | Conteúdo |
|-------|----------|
| `01-arquivos/` | Salvar dados digitados pelo usuário em um arquivo `.txt` |

## Como rodar

```bash
cd 01-arquivos
python3 input_data.py
```

O programa pede nome e idade e grava as informações em `input_data.txt`.
